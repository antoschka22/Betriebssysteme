# 191.002 VU Operating Systems


This repository contains my solutions all system-level programming assignments for my Operating Systems course at TU Wien. The projects focus on core OS concepts, including inter-process communication, process management, and networking

All source files are compiled using the C99 standard (`-std=c99`) and managed via Makefiles

## Project directory

| Assignment | Title | Description | Link |
| :---: | :--- | :--- | :--- |
| **Exercise 1** | `mygrep` & `3-Coloring` | A reduced variation of the Unix-command grep, and a randomized algorithm using inter-process communication | [Go to Exercise 1](./Exercise-1) |
| **Exercise 2** | `forksort` | A recursive merge sort implementation utilizing process forking and pipes | [Go to Exercise 2](./Exercise-2) |
| **Exercise 3** | `http` | A partial implementation of an HTTP/1.1 client and server | [Go to Exercise 3](./Exercise-3) |

## Technologies and tools used in this ourse
* **Language:** C
* **Concepts:** POSIX Shared Memory, Named Semaphores, Unnamed Pipes, Sockets
